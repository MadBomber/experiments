## clips_r2_archive/ — CLIPS/R2 (no software, vendor pages only)

CLIPS/R2 was a commercial, licensed product from Production Systems
Technologies (Charles Forgy's company): CLIPS 6.x plus his proprietary
Rete II matcher, CIDC (rules over C structs / C++ classes), and backward
chaining. No source or binary was found anywhere:

- `pst.com` now belongs to an unrelated company.
- The Wayback Machine holds only HTML pages and images for the old site
  (captures checked through 2012) — no installers or archives.
- Rete II was never published.

The files in this directory are raw Wayback Machine captures of the old
vendor pages, from `https://web.archive.org/web/<timestamp>id_/<url>`:

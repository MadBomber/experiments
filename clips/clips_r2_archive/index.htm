Production Systems Technologies

Production Systems Technologies (PST) is the most experienced supplier of high-performance rule-based systems. A spin-off of Carnegie-Mellon University, PST was founded in 1983 to develop and market state of the art rule-based tools. The founder and chief scientist of Production Systems Technologies is Dr. Charles Forgy, inventor of the Rete algorithm, and the principal designer of OPS5, the language in which the first commercially successful expert system was written. PST has a proven track record of providing practical tools for solving real world problems. Major companies in North America, Europe, and Japan have used PST tools to develop and field operational rule-based systems for over a decade.

  OPS/J :

Rules for Java

OPSJ is a tool for adding rules to Java programs. The OPSJ engine is written entirely in Java; no native code is used. A rule base developed using OPSJ can be run on any machine that supports Java version 1.3 or later.
